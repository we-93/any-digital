# Any Digital - WordPress Elementor Addon Plugin

Plugin WordPress Elementor Addon kustom dan ringan (*lightweight*) untuk **Any Digital**. Plugin ini menyediakan 7 widget Elementor pilihan yang aman, responsif, dan siap digunakan tanpa ketergantungan lisensi atau telemetri eksternal.

## 🚀 Fitur Widget Elementor

1. **Copy Text (`any-digital-copy-text`)**
   - Menyalin nomor rekening / alamat / teks ke clipboard dengan notifikasi visual *"Berhasil disalin!"*.
2. **Cover Undangan (`any-digital-cover`)**
   - Sampul / layar pembuka undangan standar dengan nama tamu dinamis (`?to=`, `?dear=`, `?kepada=`), foto mempelai, tanggal, pesan undangan, keterangan, dan pemicu musik background otomatis.
3. **Countdown Timer (`any-digital-countdown`)**
   - Hitung mundur realtime ke tanggal target acara dengan posisi Block/Inline & separator `:`.
4. **Timeline Story (`any-digital-timeline`)**
   - Perjalanan kisah (Story Timeline) dengan repeater item, foto, ikon marker, dan layout Kiri/Tengah/Kanan.
5. **Date Kit 2 (`any-digital-datekit2`)**
   - Tombol simpan acara langsung ke **Google Calendar** berdasarkan judul, deskripsi, lokasi, serta waktu mulai & selesai.
6. **WhatsApp Button (`any-digital-whatsapp`)**
   - Tombol pesan WhatsApp dengan penanganan nomor telepon otomatis (`08xxx` / `8xxx` menjadi `628xxx`), pesan yang terisi otomatis, dan opsi buka tab baru.
7. **Scroll Navigation (`any-digital-autoscroll`)**
   - Tombol navigasi scroll otomatis & manual floating 60fps dengan slider pengatur kecepatan, progress ring/bar, tooltip, notifikasi akhir halaman, dan tombol *Scroll to Top*.

---

## 🛠️ Cara Instalasi di WordPress

1. Unduh repositori ini atau kompres folder `any-digital` menjadi `any-digital.zip`.
2. Masuk ke Dashboard WordPress Anda > **Plugins > Add New > Upload Plugin**.
3. Unggah file `any-digital.zip` lalu klik **Install Now** dan **Activate Plugin**.
4. Buka Editor Elementor, dan widget **Any Digital** siap digunakan dari panel Elementor!

---

## 📄 Lisensi

Plugin dikembangkan khusus untuk penggunaan pribadi **Any Digital**.
